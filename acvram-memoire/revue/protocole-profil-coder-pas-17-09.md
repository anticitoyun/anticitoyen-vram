# Protocole — profil de pas Coder-30B régime classé (temps GPU par noyau, b=1 / b=12 / prefill 2048) + cellule GLM `-k48-calibA` b=12 sous `bf16`

instrument : `scratchpad/profil-pas-coder-17-09.py` (torch.profiler CPU+CUDA ; décodage : fenêtre pure à lot constant, graphes CUDA, 40 pas nus puis 40 pas profilés — CUPTI voit les noyaux rejoués par graphe ; prefill : moteur eager, L=2048, 3 passes nues puis 3 profilées, compteurs `fpg/fg/gemm/pile/mma` ; postes par motif de nom de noyau, 25 premiers noyaux publiés) ; GLM : `certifie-b12-15-09.py` (rondes ×2, `regime_ligne()` et `engine.regime_ligne()` ajoutés à la preuve).
commit : arbre laure 47ab28e (= main, défaut `ACVRAM_PREFILL=bf16`) ; convertis `Qwen3-Coder-30B-A3B-nvfp4` (classé 1,0144) et `GLM-4.7-Flash-srcbf16-nvfp4-k48-calibA` (classé) ; une carte sous `carte.sh`, plafond 400 W.
régime : `ACVRAM_MOE_MMA=0 ACVRAM_MOE_DECODE_MMA=0 ACVRAM_MOE_DECODE_MMA_MIN_T=5 ACVRAM_NARROW_GEMM=1`, `ACVRAM_HYBRID_SLOTS=b`, `ACVRAM_PREFILL` au défaut (bf16) ; `regime_ligne()` en tête de chaque JSON.
scellé (Sage, `sage-objectif-suivant-17-09` § 2, repris tel quel) : déquant + GEMM des experts ≥ 50 % du pas b=12 ; ≥ 60 % du prefill 2048 ; b=1 experts ≤ 40 %. Issue gênante : experts < 30 % à b=12 → le noyau fusionné gagne < ×1,4 et n'est pas premier ; le profil désigne le poste. GLM b=12 : 514 ± 25 t/s, 0,77 ± 0,04 J (chemin de décodage indépendant de `ACVRAM_PREFILL`, `kernels/__init__.py:579-593`) ; écart > 5 % → le régime touchait le décodage, une ligne éditée dans le comparatif.
ma prédiction en plus : b=12 le poste experts est majoritairement `experts_gemm` (`nvfp4_gemv_grouped*`, fusionné, sans déquant) et non `experts_dequant` — si `nvfp4_dequant_kernel` apparaît à b=12, c'est le chemin `_pile_bf16` qui est pris en décodage (MIN_T=5 < 12) et le trafic 4,5 o/param de Sage s'applique aussi au décodage ; le surcoût du profileur sur le pas nu ≤ 10 % (graphes).
falsification : b=12 experts < 50 % → prédiction Sage réfutée, le poste dominant est nommé ; prefill < 60 % idem ; b=1 > 40 % → le surcoût par pas n'est pas le chantier suivant, les experts le sont aussi à b=1 ; profil sans aucun noyau `*grouped*` → instrument aveugle (CUPTI + graphes), refaire en eager et le dire.
